# Kinetic Voice Reactor

A voice message you can feel. A concept for Telegram, built as a single working HTML file.

- Springy waveform: bars bulge under your finger and ripple as it plays
- Snap to pauses: the playhead locks onto gaps between words
- Hear while scrubbing: short audio snippets play as you drag
- Pull to bend: pull up or down to change speed and pitch, then release to lock 0.5x / 1x / 1.5x / 2x
- Records in the page with the microphone

Live demo:[ (https://fanciful-dragon-f9f6c2.netlify.app)

Run it: open index.html in a browser. No build step, no dependencies.
